# Prova diagnóstica (aula 01)

**Modo de IA: Sem IA.** Aplicada nos primeiros ~30 minutos da aula 01, antes de qualquer conteúdo de TypeScript.

## Objetivo

Medir a base real de C da turma antes do Bloco 1 (sala invertida, ritmo acelerado). Não vale nota — o resultado decide se o Bloco 1 precisa de um encontro extra (retirado da aula 15, conforme o [README raiz](../../README.md)).

## Formato

5 a 8 trechos curtos de código C (10-20 linhas cada), cobrindo: variáveis/tipos, operadores, `if`/`switch`, `for`/`while`, e uma função simples com passagem de parâmetro. Para cada trecho, o aluno escreve:

1. A saída exata que o programa produz (ou "erro de compilação" / "comportamento indefinido", se for o caso).
2. Uma frase justificando a resposta.

Sem compilar, sem IA, sem consulta a material.

## Correção

Não é aprovado/reprovado — é um termômetro. Um critério simples: **menos de 60% de acerto na turma** dispara o ajuste do encontro extra citado no README raiz.

## Banco de questões

Os trechos de código reais e o gabarito **não ficam neste repositório público** — veja `.gitignore` desta pasta. Só o formato acima é público; o arquivo `banco-questoes.md` existe apenas localmente, na máquina do professor, e pode ser trocado a cada semestre.
