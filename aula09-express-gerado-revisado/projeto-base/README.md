# projeto-base — aula09

## Como rodar

```bash
npm install
npm test
```

`GET /alunos` já está implementado e testado. As demais rotas estão só
com o `it.todo` do teste — complete o teste, peça a um agente de IA
para implementar a rota em `src/server.ts` a partir do contrato em
`recursos/template-contrato-api.md`, e revise o código antes de aceitar.
