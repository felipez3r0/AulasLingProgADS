# projeto-base — projeto final

Copie esta pasta inteira para o repositório do seu grupo (não desenvolvam
dentro deste repositório de aulas). Depois:

1. `npm install`
2. Renomeie `itens`/`Item` para o recurso principal do tema escolhido,
   ajustando `src/schema.ts`, `src/types.ts`, `src/repository.ts` e
   `src/app.ts` conforme o contrato do grupo (ver
   `recursos/template-contrato-api.md` no repositório de aulas).
3. Copie também `recursos/template-decisoes.md` (do repositório de aulas) como `DECISOES.md` na
   raiz do repositório do grupo.
4. `npm run dev` para rodar localmente, `npm test` para rodar os testes.
5. Ao final, siga `recursos/roteiro-deploy-render-turso.md` (do repositório de aulas) para publicar.
