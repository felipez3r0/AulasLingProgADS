# projeto-base — aula06

## Como rodar

```bash
npm install
npm test
```

`test/exemplo.test.ts` já passa — é só para você ver a convenção do Vitest
funcionando. `test/turma.test.ts` tem os testes reais da aula, marcados
como `it.todo(...)`: troque cada um por um `it()` de verdade (com
`expect`) antes de pedir à IA para implementar a função correspondente em
`src/turma.ts`.
